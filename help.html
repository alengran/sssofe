✍️ Markdown基础语法

标题（Headings）

使用 # 符号创建标题，支持1-6级标题：

# 一级标题（最大）
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题（最小）

快捷键：Ctrl+1 到 Ctrl+6

🎨 文本格式化

粗体（Bold）

使用双星号或双下划线包裹文本：

**这是粗体文本**
__这也是粗体文本__

快捷键：Ctrl+B

斜体（Italic）

使用单星号或单下划线包裹文本：

*这是斜体文本*
_这也是斜体文本_

快捷键：Ctrl+I

删除线（Strikethrough）

使用双波浪线包裹文本：

~~这是删除线文本~~

快捷键：Ctrl+Shift+X

粗体斜体组合

使用三颗星号同时实现粗体和斜体效果：

***这是粗体斜体文本***

下划线与高亮

• 下划线：Ctrl+U 添加下划线

• 文本高亮：选中文字后点击工具栏"H"按钮设置背景颜色

📝 列表与清单

无序列表（Unordered List）

使用 -、+ 或 * 作为列表标记：

- 列表项1
- 列表项2
  - 嵌套列表项2.1
  - 嵌套列表项2.2
- 列表项3

快捷键：Ctrl+Shift+U

有序列表（Ordered List）

使用数字加句点作为列表标记：

1. 第一项
2. 第二项
3. 第三项
   1. 嵌套有序列表
   2. 继续编号
4. 第四项

快捷键：Ctrl+Shift+O

Todo清单（Todo List）

久伴笔记特有的Unicode符号样式Todo清单，方便任务管理：

☐ 未完成的任务
☑ 已完成的任务

实际应用示例：

☀️ 晨间例事
☑ 已完成的晨练
☐ 早餐准备

📌 重点工作
☐ 完成项目报告
☐ 客户会议准备

⏰ 午休
☐ 休息30分钟

Todo快捷键：

快捷键 功能
Ctrl+Shift+D 打开模板选择对话框
Ctrl+Shift+U 快速插入未完成任务
Ctrl+Shift+I 快速插入已完成任务
Ctrl+Shift+T 切换当前行完成状态

💻 代码与语法高亮

行内代码（Inline Code）

使用反引号包裹代码，会在段落中显示为等宽字体：

在段落中插入`行内代码`示例
使用`print()`函数输出内容

快捷键：Ctrl+Shift+K

代码块（Code Block）

使用三个反引号包裹代码，可指定语言以启用语法高亮：

```python
def hello_world():
    print("Hello, World!")
    return True
```

快捷键：Ctrl+Shift+P

🔗 链接与图片

链接（Links）

基本语法：

[链接文本](链接地址)

示例：

[久伴笔记官网](https://jiuban.me)
[GitHub项目](https://github.com/example/project)

高级用法 - 带标题的链接：

[链接文本](链接地址 "鼠标悬停提示")

快捷键：Ctrl+Shift+L

图片（Images）

基本语法：

![图片描述](图片路径)

示例：

![久伴笔记logo](./files/logo.png)
![截图](https://example.com/screenshot.png)

快捷键：Ctrl+Shift+I

图标（Icons）

点击工具栏"图标"按钮，在图标选择对话框中浏览和选择图标插入到笔记中。

📊 表格

基本语法

| 表头1 | 表头2 | 表头3 |
| ----- | ----- | ----- |
| 内容1 | 内容2 | 内容3 |
| 内容4 | 内容5 | 内容6 |

快捷键：Ctrl+T

对齐方式

使用冒号控制列的对齐方式：

| 左对齐 | 居中对齐 | 右对齐 |
| :----- | :------: | -----: |
| 内容1  |  内容2   |  内容3 |
| 内容4  |  内容5   |  内容6 |

说明：

• :----- 左对齐

• :----: 居中对齐

• -----: 右对齐

💬 引用与分隔线

引用（Blockquotes）

使用 > 符号创建引用块：

> 这是一段引用文本
> 可以有多行

嵌套引用：

> 第一层引用
>> 第二层引用
>>> 第三层引用

快捷键：Ctrl+Shift+Q

水平分隔线（Horizontal Rule）

使用三个或更多的连字符、星号或下划线创建水平分隔线：

---
***
___

快捷键：Ctrl+Shift+-

❓ 常见问题

Q: 为什么我的代码没有高亮？
A: 请确保在代码块的起始位置指定了正确的语言标识符，例如 ```python 而不是 ```。
Q: Todo清单的符号可以自定义吗？
A: 当前版本使用固定的Unicode符号（☐ 和 ☑），未来版本可能会支持自定义符号。
Q: 图片上传后存储在哪里？
A: 图片会自动复制到 notes/files 目录，路径会自动更新为本地相对路径。
Q: 如何导出笔记？
A: 久伴笔记支持导出为HTML、PDF等格式，点击"文件"菜单中的"导出"选项即可。
Q: 支持云同步吗？
A: 久伴笔记是本地存储软件，支持通过第三方云盘（如坚果云、Dropbox等）同步笔记文件夹实现云端备份。
