📄 软件介绍

今天给大家分享一个小工具——**MicaRec 轻录屏**，免费、无广告、免安装，解压就能用。它的设计思路很简单：**你负责点开始，参数交给软件自己决定**。

### 最省心的一点：自动选显卡

MicaRec 启动时会自动检测你电脑上的显卡编码器：NVIDIA 独显、Intel 核显、AMD 显卡，谁强用谁，自动给你配好当前硬件条件下画质和性能最平衡的参数。独显优先、核显兜底、CPU 软编保底，全自动切换，你根本不用知道 NVENC、QSV、AMF 是什么。

实测 CPU 占用非常低，录游戏、录软件演示都不会明显拖慢电脑。

### 三种录制模式，想录哪里录哪里

- **全屏录制**：多显示器用户可以在下拉框里选要录哪块屏幕
- **窗口录制**：选中一个窗口，哪怕它被别的窗口挡住，也能完整录下来，做教程神器
- **区域录制**：直接在屏幕上拖框框选，还支持锁定 16:9、4:3、21:9 比例，录制时四周有红框提示安全范围，不会录偏

### 三种输出格式，按需选择

- **MP4**：通用性最好，日常推荐
- **MKV**：更抗损坏，录到一半断电崩溃，已录部分依然能播放
- **GIF**：直接出动图，适合做表情包、短演示片段（注意 GIF 不支持声音）

画质有**高质量 / 均衡 / 小体积**三档，日常用默认的均衡档就行；帧率从 15 到 120 可选，录高刷游戏可以开到 60 以上。

### 声音和画面，都能精细控制

- 系统声音、麦克风**独立开关**，还能指定具体麦克风设备。只录游戏声、不想暴露自己说话？关掉麦克风就行
- 需要露脸的话，可以开**摄像头小窗**，画中画位置四角任选

### 三个快捷键，全程不碰鼠标

| 快捷键 | 功能 |
| --- | --- |
| Ctrl + Alt + 1 | 开始 / 停止录制 |
| Ctrl + Alt + 2 | 暂停 / 继续 |
| Ctrl + Alt + 3 | 停止并保存 |

快捷键是**全局**的，窗口最小化、缩到托盘时依然有效。录制时主界面会自动最小化，不挡你干活；停止后弹通知，点一下就能打开文件所在文件夹。

其他细节也很舒服：设置改动**即时自动保存**、简体中文/英文一键切换、录制崩溃后已录内容保留、日志完整方便排查问题。
